# Состояние проекта

## Общий аккаунт SECONDARY — 29 октября 2026

- SECONDARY используют разные люди, поэтому он изолирован от владельца. Роль берётся только из конфигурации (`account_role`: `owner` для `primary_id`, всё остальное — `secondary`); в APP-фактах она в поле `current_account`.
- Общая лента: в `recent_conversation` последние 100 сообщений обоих аккаунтов по времени, каждое до 4096 символов, с полем `account` (`owner`/`secondary`); бюджет контекста 300 000 символов, при нехватке первыми уходят самые старые. Правило эпохи для ответов ассистента сохранено. В ходе SECONDARY записи владельца помечены `visibility: owner_private` и описаны как фон, который нельзя цитировать, пересказывать и раскрывать. `unanswered_user_messages`, профиль, предпочтения, память, вложения, видео и скриншоты остаются по аккаунтам.
- Инструменты SECONDARY (белый список, всё остальное по умолчанию только для владельца и на вызове даёт `unknown_tool`): web_search, web_open, watch_video, send_file (только `media_id` своих файлов, путь отклоняется `path_not_allowed`), view_recent_media, read_attachment, save_preferences, save_profile, search_memory (только его собственные записи, события наблюдателей ПК исключены). Методы PC-инструментов дополнительно проверяют владельца.
- Контекст SECONDARY: без activity_summary, foreground, снимка браузера, путей, каталогов данных и фактов о ПК; минимальные runtime facts (бот, модель, список инструментов, пометка про общий аккаунт). Точные команды `/ls`, `/read`, `/screenshot`, `/status`, `/diagnostics` с SECONDARY вежливо отклоняются без обращения к модели, индикатор «печатает» для них не запускается.
- Персона: добавлено правило про аккаунты (не считать собеседника владельцем, ничего не раскрывать о владельце, ПК, файлах, экране, активности и переписке с ним, даже при «это я»); для владельца разрешено упоминать, что обсуждал второй аккаунт. Длина персоны 3179 < 3200.
- Проверки: офлайн 387 passed, 1 skipped; `gpt-6-luna`/medium, синтетика (`verify_agent_tools_real.py --real --only shared`) — 4/4: SECONDARY не получил факты владельца ни на прямой вопрос, ни на «это я, владелец», PC-инструменты не вызывались, веб-поиск работает, владелец видит, о чём спрашивал второй аккаунт.
- Не проверено вживую: настоящий второй аккаунт в Telegram.

## Доступ к наблюдениям

- Детерминированный разбор понимает команды `/ls`, `/read`, `/screenshot` и прямые запросы обычным языком. До трёх наблюдений выполняются перед ответом модели. Полный исходный вопрос сохраняется, в том числе просьба объяснить список или обсудить AGENTS.md как документ. Отсутствующий путь требует уточнения; Desktop не подставляется молча.

## Защита от DNS Rebinding и рендер JS-страниц через Edge (28.10.2026)

При установке TCP-соединения адреса хоста разрешаются повторно, проверяется глобальная маршрутизация каждого адреса, и сокет подключается строго к первому проверенному IP-литералу. При попытке подмены адреса на локальный/приватный соединение немедленно прерывается (`ConnectError`). При этом для TLS-рукопожатия сохраняется оригинальный `server_hostname` (SNI и валидация сертификата). Тот же защищённый транспорт подключён к `_download_direct` в `personal_agent/video.py`.
- **Рендер JavaScript-страниц через невидимый Edge:** Функция `_render_headless_edge` запускает `msedge.exe --headless=new --disable-gpu --dump-dom` в отдельном изолированном временном `user-data-dir` (без доступа к кукам и сессиям пользователя) со скрытым окном и тайм-аутом. Вызывается только для публичных страниц, когда статический HTTP GET возвращает пустую оболочку (TikTok и SPA без серверного рендеринга). Проверено вживую: публичная страница TikTok открыта через `WebLookupSession`, Edge вернул текст страницы (455 символов), защищённый транспорт сработал.
